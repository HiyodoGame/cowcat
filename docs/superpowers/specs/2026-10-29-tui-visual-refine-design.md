# TUI 侧栏层级与 Braille 点阵猫设计

> 本设计由 2026-10-29 实机截图审查与随后“按照计划执行”的确认产生，修订 ADR-173 的侧栏高度和猫咪光栅方案。

## 1. 意图与目标

实机中，固定侧栏虽然都有标题和空态，但面板机械均分高度且没有可见边界，导致文字漂浮、空白失控。82×46 光栅经 41×23 象限单元渲染后，猫占据 95% 左栏宽度，并由大量 `█` 形成实心像素观感。

本次目标：

- 用原生细边框和一致的标题样式明确模块边界，空态区块仍全部保留。
- 面板按内容自然增高，溢出时才压缩；猫咪缩小并固定在左栏底部。
- 用 64×40 逻辑点、2×4 Braille 子点渲染为约 32×10 终端单元，保持黑白灰和已确认的六种眼神。
- 右侧短字段单行显示，长路径按路径段换行；中央空会话有紧凑引导，输入框提示多行快捷键。

## 2. 非目标与约束

- 不改协议、内核事件、端口、模型、工具行为、响应式断点或包版本，不新增依赖。
- 不重做消息流、模态对话框、窄终端 dock，不新增左右栏独立开关。
- 不把文字重新放进猫咪画布，不恢复彩色、黑块眼、嘴巴、额外奶斑或右耳尖。
- 所有 UI 边框继续由 OpenTUI 原生 Box 绘制，不手拼装饰边框。

## 3. 侧栏布局

左栏顺序保持待办 / 子代理 / 后台任务 / 猫咪。每个活动面板使用原生细边框、中性边框色和原生标题；品牌绿只强调运行状态，不再给所有标题铺底。

空态面板高度由边框和实际内容决定：待办约 4 行，子代理和后台任务约 3 行。内容增多时自然增长；总高度不足时，从最高面板逐步压缩到最小 3 行，列表仍按项目截断并显示 `另有 N 项`。多余空间留在后台任务与猫咪之间，猫咪底部对齐并在 43 列左栏内水平居中。

右栏保持上下文 / 会话 / 工作区 / 文件变更。短值与标签同行，空值只占一行，长值保留两行或按路径段换行。文件变更占剩余弹性空间，其它信息面板按内容自然增高。

中央仅在完全无会话内容时显示紧凑的“开始新会话”原生面板和一条输入提示；信任、审批和 composer 行为不变。状态文字继续由现有状态栏承担。

## 4. Braille 点阵猫

- 每帧固定 64×40 逻辑点，左右镜像对称；几何按新网格直接采样，不复制旧 2×2 像素。
- 每终端单元表达 2×4 点，因此固定为 32 列×10 行。
- 使用 Unicode Braille 字形，不使用象限实块，不设置猫咪背景实色；透明区域保持透明。
- 背景只保留稀疏、低对比灰点，不再铺满密集矩形底纹。
- 单元格内以确定优先级保留眼睛、鼻点、面罩和轮廓；灰阶由点级角色与空间分布表达。
- 保留浅灰虹膜、中灰瞳孔和高光，单个小灰鼻点；鼻点由同一终端单元内的两个居中逻辑点构成，以同时满足偶数网格的严格对称；idle 眨眼与轻微明暗呼吸、thinking 同向视线、tools 半阖、approval 睁大、success 弯眼、failed 垂眼。
- 保留原状态优先级、动画截止时间与 `COWCAT_ANIMATIONS=off` 行为。

## 5. 验收

- 64×40 帧对称、单鼻点、六种眼形可区分；Braille 覆盖 2×4 位映射，透明处无幻影点，原生挂载尺寸为 32×10。
- 160×32 下三个活动面板、10 行猫咪和右栏全部可见；160×40 空态面板不再均分高度；长列表仍有准确溢出计数。
- 所有活动面板具有原生边框与标题；空态顺序不变。
- 短字段紧凑、长路径不无故切断路径段，文件变更加长时仍有界。
- 空会话显示引导；有消息、流式内容或待运行工具时不显示该空态。
- TUI build、ESLint、全量测试、探针、四包测试和 tarball 检查通过；真实 Tabby/Windows Terminal 的字形与观感单独验收，不用 headless 结果冒充。
