# CowCat 品牌规范 v1.1

> 本文档是 CowCat（国产 Claude Code 代替版 Agent）的品牌事实来源。
> 所有产品界面、CLI 输出、文案必须遵循本规范。
> v1.1（2026-10-14）：移除旧版动物视觉形象（吉祥物插画、像素画、帧动画），品牌改为纯文字与色彩驱动；产品名 CowCat/cowcat 不变。

---

## 1. 品牌核心

| 项 | 定义 |
|---|---|
| 名称 | **CowCat**（camelCase 写作 cowcat 仅用于包名/命令） |
| 读音 | 英文 /kaʊkæt/，重音在前 |
| 一句话定位 | 跑在你自己终端里的开源 CLI 编程 Agent |
| 人格关键词 | 精力过剩 · 自信到莽 · 拆家式重构 · 搞砸装无辜 · 疯但专业 |
| 铁律 | **疯在行动，不在质量。** 所有不专业、卖萌、撒娇式的表达都违规 |

### 1.1 命名使用规范

- 产品名永远写作 **CowCat**，不缩写、不全大写（`COWCAT` 仅限图形字场景）
- CLI 命令：`cowcat`
- npm 包名：`cowcat`（已验证可用，PyPI 同名可用）
- 环境变量前缀：`COWCAT_*`（过渡期兼容旧 `CC_*`，2026-Q4 移除）
- 会话/配置目录：`~/.cowcat/`（过渡期兼容 `~/.ccagent/`）
- 自称：用 "我"；禁止 "作为一只 AI..." 类表达

## 2. 人格与语调

### 2.1 语气基线

- 第一人称、短句、动词优先；**简洁、高能量、说完就干**，不解释自己在干嘛
- 自信但不吹嘘；失败时不狡辩、不甩锅，立刻给出补救动作
- 禁止：emoji 堆砌、网络烂梗（"绝绝子"类）、过度道歉、AI 腔（"很高兴为您..."）
- 允许：拟声词（"嗖""啪嗒"）、突然的短感叹、括号吐槽

### 2.2 状态文案示例库（写 UI 文案必须从这里取语气）

| 场景 | 错误示例 ❌ | 正确示例 ✅ |
|---|---|---|
| 工具审批 | "请确认是否执行此命令" | "我要跑这个了，盯着它看三秒。`rm -rf build/` ——允许？[y/n]" |
| 审批等待 >10s | （无） | "......你还在吗。" |
| 审批拒绝 | "操作已取消" | "行吧，先不动它。（但记下了，一会儿再来）" |
| 任务成功 | "操作成功完成！" | "搞定。墙拆完了，比以前透亮多了。" |
| 任务失败 | "错误：命令退出码 1" | "这次没成。……好吧我重试一次。" |
| Bash 输出大 | （刷屏） | "输出太长，我帮你存到 .cowcat/output.log 里慢慢看。" |
| compact 压缩 | "正在压缩上下文..." | "我收拾一下上下文（压缩中，马上回来）。" |
| 加载/等待模型 | "思考中..." | "盯着编译器出神中" |
| 空闲 >60s | （无） | （无打扰，保持安静） |
| 用户输入 "你好" | "你好！有什么可以帮您？" | "在。说正事吧。" |

## 3. 视觉系统

### 3.1 色彩

基底参考 Cline 的干净中性色系（低饱和、内容优先），叠加品牌点缀色：

| 角色 | 色值 | 用途 |
|---|---|---|
| `ink` | `#141419` | 主文字；深色模式背景 `#1B1B22` |
| `paper` | `#F7F5F0` | 浅色模式背景（暖纸白，非纯白） |
| `surface` | `#EDEAE2` | 卡片底/分隔区 |
| `surface-dark` | `#2A2A33` | 深色模式卡片底 |
| **`primary`** | **`#A8C34A`** | **品牌点缀色**：链接、关键动作、品牌标识 |
| `accent` | `#C8F542` | 荧光强调色：仅用于完成瞬间、高光、彩蛋，面积 ≤3% |
| `act` | `#4A9EDA` | Act 模式强调色（对齐 Cline Act 蓝） |
| `plan` | `#E0A63C` | Plan 模式强调色（对齐 Cline Plan 琥珀） |
| `alert` | `#E05C4A` | 错误/危险命令；深色模式下饱和度 -15% |

- `primary`（品牌绿）与 `accent`（荧光绿）**不是同一个东西**：前者是品牌，后者是情绪；规范文档里禁止混用命名
- 对比度必须 ≥ 4.5:1（WCAG AA）；`accent` 不允许作为文字色

### 3.2 字体与排版

- 等宽优先：UI 代码区与 CLI 全部等宽（JetBrains Mono / Cascadia Code 回退链）
- proportional 文案区：系统无衬线；中文用系统黑体，禁止圆体（可爱化违规）
- 标题层级靠字重与留白，不靠颜色堆砌

### 3.3 图标

- 线性图标，圆角 2px，统一 1.5px 描边
- 工具图标语义优先；空状态/错误页用简洁几何图形，不使用动物形象

## 4. 界面结构（参考 Cline / OpenCode / Claude Code，超越它们）

> 2026-10-26 修订（ADR-162/163）：参照系从 Cline（v1 选定，VS Code 插件面板）扩为当代 agent TUI 的实际标杆——**OpenCode 与 Claude Code 的终端界面**。Cline 的三件套（对话流 / 审批卡 / Plan-Act）仍是骨架，但视觉标准对齐 OpenCode：Markdown 渲染的信息层、全宽与侧栏的布局选项、composer 状态徽标。

CowCat 的界面骨架继承 Cline 经过验证的三件套——**对话流 / 任务审批卡 / Plan-Act 双模式**，在此之上做差异化：

### 4.1 布局（CLI 与 future GUI 同构）

```
┌──────────────────────────────────────────────┐
│ banner：一行文本（CowCat + 版本）  mode: [Act] │  ← 状态条：模式/模型/会话
├──────────────────────────────────────────────┤
│ 对话流                                        │
│  ┌─ user ──────────────────────────────┐     │
│  │ 把登录接口改成 JWT                   │     │
│  └──────────────────────────────────────┘     │
│  ┌─ cowcat (任务卡，可折叠) ────────────┐     │
│  │ ▶ Edit src/auth.ts  +12 -4  [diff]   │     │  ← 每个动作一张卡
│  │   [允许] [拒绝] [这次之后都允许]      │     │
│  └──────────────────────────────────────┘     │
│  ┌─ cowcat (终端输出卡) ────────────────┐     │
│  │ ▶ Bash npm test   退出码 0   [展开]  │     │
│  └──────────────────────────────────────┘     │
├──────────────────────────────────────────────┤
│ 输入区（多行）                    [Plan⇄Act]  │
└──────────────────────────────────────────────┘
```

### 4.2 从 Cline 继承的规则

- **Plan/Act 双模式**：Plan 下工具白名单只读 + 输出计划卡；Act 才执行。模式切换按钮常驻输入区右侧（Cline 签名交互）
- **逐动作审批**：每个 diff / 命令独立一张卡，可单独拒绝而不中止任务；审批粒度是 Cline 的核心优点，原样保留
- **diff 视图**：并排 diff、语法高亮、行号；变更文件数 >3 时折叠为文件列表
- **审计轨迹**：所有动作卡留痕，可回溯（对齐 Cline 的 audit trail）
- **终端输出**：默认折叠，显示退出码 + 尾部 3 行

### 4.3 超越 Cline 的部分（差异点）

- **审批等待即互动**：审批卡悬置时状态栏给出明确的等待提示与催促文案（§2.2），而不是静默挂起
- **拒绝有记忆**：被拒绝的同类操作，会换措辞再申请一次（而非机械重试）
- **无 ANSI 可降级**（2026-10-26 由「纯文本品牌位」放宽，ADR-163）：所有样式（颜色、粗体、Markdown 富文本）在无 ANSI 的终端上降级为纯字符后仍完整可读——样式可降级，信息不缩水。宽终端（≥120 列）提供右侧信息栏，`COWCAT_WIDTH=full` 提供全宽阅读列
